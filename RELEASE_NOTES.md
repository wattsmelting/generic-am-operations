# Release Notes

## v0.4.0 — Linked operations development prototype
- Expanded the familiar themed GUI with parts, powder transactions, personnel and training, NCR/CAPA, inspections, suppliers, audit, risk, validation, change control and management review modules.
- Added an empty-on-first-run SQLite development database and generic record creation API.
- Added basic foreign-record ID checks for builds, parts, powder transactions, training and quality records.
- Added a part genealogy lookup and creation-event log.
- Added context-sensitive page help and full built-in manual navigation.
- Preserved one-click Windows setup, test, release check and GUI launch.

### Known gaps
Not equivalent to the private V3.7.4 system. No authenticated users, permissions, approvals, signatures, immutable records, complete powder genealogy, electronic document control, enforced qualification or validated QMS compliance. **Development only.**
